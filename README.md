# Komentář k zákonu č. 311/2013 Sb., o převodu vlastnického práva k jednotkám a skupinovým rodinným domům některých bytových družstev a o změně některých zákonů

Otevřený komentář k zákonu o převodu jednotek a skupinových rodinných domů některých bytových družstev — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; bezúplatný převod, oprávněný člen, smlouva o převodu, úvěr a zástavní právo, nástavby a vestavby, služebnost bytu, vrácení státních příspěvků a vznik společenství vlastníků.

Konsolidované znění: dokument e-Sbírky `SB-2013-00311_2020-07-01`.
